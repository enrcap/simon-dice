# Simón Dice · Visión por Ordenador I

Este repositorio reconstruye por etapas un proyecto ya terminado. Las ramas muestran dependencias técnicas y el reparto previsto; las fechas corresponden a la reconstrucción y no documentan cuándo se programó cada función.

Instala las dependencias con `python -m pip install -r requirements.txt` y abre la cámara con `python -m src.main`.
